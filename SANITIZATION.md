# How this repository was prepared

The material in this repository was derived from a private demonstration lab and converted into a neutral reference
implementation before publication. This page describes the conversion, so that you know what to expect and what you must
supply yourself. No other repository, document or environment is referred to.

## Replaced with placeholders

| In the original | In this repository |
|---|---|
| Subscription, tenant, object, principal and other environment identifiers | `<SUBSCRIPTION_ID>`, `<TENANT_ID>` and sentinel GUIDs `00000000-0000-0000-0000-0000000000NN` (public Azure and Microsoft constants are kept) |
| Deployment regions | `<PRIMARY_REGION>` in commands and files, "the primary region" in prose (the secondary region, Southeast Asia, is kept because some Arc management features need it and the scripts name it literally) |
| Globally unique name suffixes and storage account names | `<SUFFIX>` and `sthv<role><SUFFIX>` |
| Names and sample database names that carried an environment-specific prefix or theme | `rg-hyperv-arc-monitor-demo`, `hv-...`, `HvSqlMemory_CL`, `HvLinuxDisk_CL`, `OrdersDemo`, `BillingDemo`, `DemoDb` and similar |
| Notification recipients and sender addresses | `operator@example.com` and a sentinel Azure Communication Services sender |
| Grafana endpoints | `<GRAFANA_ENDPOINT>` |
| Time-zone labels | "LT", defined as UTC+7 in the worked example, with UTC alongside |
| Logos, banners and e-mail brand images | Generated neutral placeholders |

## Left out

* Recorded artefacts: exports, query results, reports and screenshots.
* Dated notes and values that only made sense for the original environment.
* One-off helper scripts for that environment, and response files that scripts write at run time.
* A run-time dashboard snapshot that embedded recorded report data (the report dashboard is generated by the application).
* Time-limited clean-up tags.
* References to environment-specific tooling.
* Credentials of any kind. The lab kit never contained secrets; it reads them from a private, git-ignored
  `ENVIRONMENT.txt` that you create yourself.

## Adjusted so that it still works

Names, paths and commands were changed consistently across the code, the dashboards, the queries and the documentation.
The shift-report application was re-pinned after the conversion (its policy fingerprints exact file bytes) and its 173
offline tests pass; the tests that depended on a recorded workbook now use a deterministic synthetic one. The Update
Manager window and the webhook expiry are computed when the script runs. Example dates in the shift-report fixtures, the
maintenance-window sample and the dashboard links that preset a time window were shifted consistently, so every relation
between the dates is unchanged.

## Checked

Every text file was scanned for identifying tokens, GUIDs, e-mail addresses, IP addresses and secret patterns; JSON,
PowerShell and Python files were parsed; the documentation was reviewed for context that scanners cannot see; and the
published tree is scanned again after it is pushed.

Not checked: a complete rebuild of the lab from this repository in a fresh subscription. The scripts were parsed and the
offline tests were run, but the Azure-facing steps were not re-executed after the conversion.

If you still find something that should not be here, please open an issue (or contact the owner privately) so that it can
be removed.
